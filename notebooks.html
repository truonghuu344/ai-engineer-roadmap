Cách mở notebook

  1. Bấm Bài tập để tải file .ipynb về máy.
  2. Vào colab.research.google.com, chọn File → Upload notebook rồi chọn file vừa tải.
  3. Notebook cần GPU thì vào Runtime → Change runtime type → T4 GPU.
  4. Chạy từ trên xuống, viết code vào chỗ TODO, rồi chạy ô ✅ ngay sau để chấm.
Các notebook mới sẽ được thêm vào đây theo lộ trình.
