Hướng dẫn

Mở notebook trên Colab

1 · Tải về

Bấm Bài tập để tải file .ipynb về máy.

2 · Mở trên Colab

Vào colab.research.google.com → File → Upload notebook. Bài cần GPU thì chọn Runtime → T4 GPU.

3 · Làm và tự chấm

Chạy từ trên xuống, viết code vào chỗ TODO, chạy ô ✅ ngay sau đó. Thấy ✅ là xong phần đó.
