PyTorch cơ bản: tensor, autograd, nn.Module

Giai đoạn P0 · Nền móngTuần 1–3Có nội dung đầy đủ

PyTorch là thư viện deep learning phổ biến nhất trong nghiên cứu và ngày càng phổ biến trong sản phẩm. Bài này dạy cách dùng PyTorch, từng mảnh một: tensor (mảng số của PyTorch), chạy trên GPU, autograd (tự tính đạo hàm), rồi ghép thành model, loss, optimizer và vòng train. Bạn cần numpy (P0.2) và ý nghĩa của đạo hàm (P0.5). Còn vì sao mạng nơ-ron học được thì để dành cho P2.1; ở đây ta luyện tay cho quen.

PyTorch cần máy tính thật để chạy nên các đoạn code trong bài hiện kết quả đã chạy sẵn. Muốn tự sửa và chạy lại, bấm nút COLAB ở cột bên phải: Colab có sẵn PyTorch, không cần cài gì.

PyTorch cho bạn đúng ba thứ: tensor giống mảng numpy, chạy được trên GPU; autograd tự tính đạo hàm; và các khối dựng sẵn (lớp, hàm loss, thuật toán tối ưu) để ghép model.

Lỗi hay gặp

Đưa dữ liệu float64 vào model. Dữ liệu đọc bằng numpy hay pandas thường là float64. Đưa thẳng vào model sẽ báo lỗi kiểu:

RuntimeError: mat1 and mat2 must have the same dtype, but got Double and Float

Double là float64, Float là float32. Sửa: torch.tensor(X, dtype=torch.float32) hoặc torch.from_numpy(X).float().

autograd: tự tính đạo hàm

Đây là phần "phép màu" của PyTorch. Đánh dấu một tensor bằng requires_grad=True, tính một biểu thức từ nó, gọi .backward(): PyTorch tính đạo hàm của kết quả theo tensor đó và cất vào .grad.

w = torch.tensor(2.0, requires_grad=True)
y = w ** 2 + 3 * w                      # y = w² + 3w
y.backward()                            # tính dy/dw
print(y.item(), w.grad.item())          # y = 10; dy/dw = 2w + 3 = 7 tại w = 2
Kết quả khi chạyđã chạy sẵnMở trên Colab ↗
10.0 7.0

Kiểm tra bằng tay (P0.5): đạo hàm của w² + 3w là 2w + 3, tại w = 2 bằng 7. Khớp.

Đạo hàm của một loss

Với model đơn giản nhất dự đoán = w·x + b và một mẫu (x, y), loss bình phương là (w·x + b − y)²:

w = torch.tensor(1.0, requires_grad=True)
b = torch.tensor(0.0, requires_grad=True)
x, y = torch.tensor(2.0), torch.tensor(5.0)

pred = w * x + b                        # 2
loss = (pred - y) ** 2                  # (2 - 5)² = 9
loss.backward()
print(loss.item(), w.grad.item(), b.grad.item())
Kết quả khi chạyđã chạy sẵnMở trên Colab ↗
9.0 -12.0 -6.0

Bằng tay: ∂loss/∂w = 2·(pred − y)·x = 2·(−3)·2 = −12, ∂loss/∂b = 2·(pred − y) = −6. Gradient âm nghĩa là tăng w thì loss giảm, đúng vì dự đoán 2 đang nhỏ hơn đáp án 5.

Gradient cộng dồn

w = torch.tensor(2.0, requires_grad=True)
for i in range(3):
    y = w ** 2 + 3 * w
    y.backward()
    print("lần", i + 1, "w.grad =", w.grad.item())   # 7, 14, 21: cộng dồn chứ không ghi đè!
# xóa gradient về 0
w.grad.zero_()
print("sau zero_:", w.grad.item())

lần 2 w.grad = 14.0

PyTorch cộng gradient mới vào .grad cũ thay vì ghi đè. Vì vậy mỗi bước train phải xóa gradient trước (optimizer.zero_grad()). Quên bước này là lỗi kinh điển: model vẫn chạy, không báo lỗi gì, chỉ học sai.

Tắt autograd khi không cần

Khi cập nhật tham số hoặc khi chỉ dự đoán (không train), bọc code trong with torch.no_grad(): để PyTorch không ghi đồ thị: nhanh hơn, tốn ít bộ nhớ hơn. Muốn lấy một tensor ra khỏi đồ thị (để vẽ, để chuyển sang numpy) thì dùng .detach(): loss.detach().numpy().

Tự train bằng autograd

Ghép mọi thứ: tìm w, b cho dữ liệu được tạo theo y = 2x + 1 cộng chút nhiễu. Mỗi bước: dự đoán, tính loss, tính gradient, đi một bước ngược hướng gradient (gradient descent, P0.5), xóa gradient.

torch.manual_seed(0)
X = torch.rand(100) * 10                       # 100 giá trị x từ 0 tới 10
Y = 2 * X + 1 + torch.randn(100) * 0.5         # đáp án thật: w = 2, b = 1, cộng nhiễu

w = torch.tensor(0.0, requires_grad=True)
b = torch.tensor(0.0, requires_grad=True)
lr = 0.01                                      # learning rate: độ dài mỗi bước

for step in range(1001):
    pred = w * X + b
    loss = ((pred - Y) ** 2).mean()            # MSE: trung bình bình phương sai số
    loss.backward()                            # tính w.grad, b.grad
    with torch.no_grad():                      # cập nhật tham số, không ghi đồ thị
        w -= lr * w.grad
        b -= lr * b.grad
    w.grad.zero_(); b.grad.zero_()             # xóa gradient cho bước sau
    if step % 200 == 0:
        print(f"bước {step:4d}: loss = {loss.item():.3f}, w = {w.item():.3f}, b = {b.item():.3f}")

nn.Module, loss và optimizer

Viết tay w, b như trên ổn với 2 tham số, nhưng mạng thật có hàng triệu. PyTorch đóng gói sẵn:

  • torch.nn có các lớp (layer) chứa tham số: nn.Linear(vào, ra) là phép x @ W.T + b.
  • Hàm loss: nn.MSELoss() cho hồi quy, nn.CrossEntropyLoss() cho phân loại.
  • torch.optim có các thuật toán cập nhật tham số: SGD, Adam...
import torch.nn as nn
lin = nn.Linear(3, 2)                          # 3 đầu vào, 2 đầu ra
print(lin.weight.shape, lin.bias.shape)        # W: (2, 3), b: (2,)
n_params = sum(p.numel() for p in lin.parameters())
print("số tham số:", n_params)                 # 3*2 + 2 = 8
print(lin(torch.randn(4, 3)).shape)            # batch 4 mẫu → (4, 2)
Kết quả khi chạyđã chạy sẵn cần PyTorchMở trên Colab ↗
torch.Size([2, 3]) torch.Size([2])
số tham số: 8

Một model là một class kế thừa nn.Module, gồm hai phần: __init__ khai báo các lớp, forward mô tả dữ liệu đi qua chúng thế nào (cách viết class đã gặp ở P0.1):

class MLP(nn.Module):
    def __init__(self):
        super().__init__()                     # dòng bắt buộc đầu tiên
        self.l1 = nn.Linear(2, 16)
        self.l2 = nn.Linear(16, 2)
    def forward(self, x):
        h = torch.relu(self.l1(x))             # lớp 1 rồi ReLU (giữ số dương, số âm thành 0)
        return self.l2(h)                      # lớp 2: 2 điểm số, một cho mỗi lớp

model = MLP()
print(model)
print("số tham số:", sum(p.numel() for p in model.parameters()))   # (2*16+16) + (16*2+2) = 82
Kết quả khi chạyđã chạy sẵnMở trên Colab ↗
MLP(
  (l1): Linear(in_features=2, out_features=16, bias=True)
  (l2): Linear(in_features=16, out_features=2, bias=True)
)
số tham số: 82

Gọi model(x) là PyTorch tự gọi forward(x). Với model chỉ xếp các lớp nối tiếp, viết ngắn hơn bằng nn.Sequential(nn.Linear(2, 16), nn.ReLU(), nn.Linear(16, 2)).

Vòng train 5 dòng

Mọi vòng train PyTorch, từ hồi quy tuyến tính tới model ngôn ngữ lớn, đều có năm dòng này:

loss_fn = nn.CrossEntropyLoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)    # model MLP ở trên
xb = torch.randn(8, 2)                                      # một batch giả: 8 mẫu, mỗi mẫu 2 số
yb = torch.randint(0, 2, (8,))                              # nhãn 0 hoặc 1

for step in range(3):
    optimizer.zero_grad()          # 1. xóa gradient cũ
    pred = model(xb)               # 2. forward: dự đoán
    loss = loss_fn(pred, yb)       # 3. tính loss
    loss.backward()                # 4. backward: tính gradient
    optimizer.step()               # 5. cập nhật tham số theo gradient
    print(step, loss.item())       # loss giảm dần trên batch này

Lỗi hay gặp

Sai kiểu nhãn cho CrossEntropyLoss. nn.CrossEntropyLoss muốn: dự đoán là điểm thô (logit) shape (N, số lớp), chưa qua softmax; nhãn là số nguyên (int64) shape (N,), mỗi số là chỉ số lớp. Nhãn kiểu float, hay nhãn dạng one-hot shape (N, số lớp) dù không phải lúc nào cũng báo lỗi nhưng cho kết quả khác ý bạn. Tự áp softmax trước khi đưa vào loss cũng sai, vì loss này đã tự làm softmax bên trong.

Dataset và DataLoader

Train trên cả bộ dữ liệu một lúc thì tốn bộ nhớ; thường chia thành các batch nhỏ (32, 64 mẫu). DataLoader làm việc đó: chia batch, xáo thứ tự mỗi epoch, ghép mẫu thành tensor (đúng như np.stack ở P0.2).

from torch.utils.data import TensorDataset, DataLoader

X = torch.randn(100, 2)
y = torch.randint(0, 2, (100,))                # nhãn 0 hoặc 1
ds = TensorDataset(X, y)                       # ds[i] trả về cặp (X[i], y[i])
loader = DataLoader(ds, batch_size=32, shuffle=True)
print(len(ds), len(loader))                    # 100 mẫu, 4 batch (32 + 32 + 32 + 4)
for xb, yb in loader:
    print(xb.shape, yb.shape)

Vòng train đầy đủ

Phân loại điểm trên mặt phẳng thành 2 lớp. Mỗi epoch là một lượt đi qua toàn bộ dữ liệu:

import torch, torch.nn as nn
from torch.utils.data import TensorDataset, DataLoader

torch.manual_seed(0)
n = 400
X = torch.randn(n, 2)
y = ((X[:, 0] ** 2 + X[:, 1] ** 2) > 1.2).long()   # lớp 1 nếu điểm nằm ngoài vòng tròn
train_ds = TensorDataset(X[:300], y[:300])
val_X, val_y = X[300:], y[300:]                     # 100 điểm giữ riêng để kiểm tra

model = nn.Sequential(nn.Linear(2, 16), nn.ReLU(), nn.Linear(16, 2))
loss_fn = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)
loader = DataLoader(train_ds, batch_size=32, shuffle=True)

for epoch in range(1, 61):
    model.train()
    for xb, yb in loader:
        optimizer.zero_grad()
        loss = loss_fn(model(xb), yb)
        loss.backward()
        optimizer.step()
    if epoch in (1, 3, 10, 30, 60):
        model.eval()
        with torch.no_grad():
            acc = (model(val_X).argmax(dim=1) == val_y).float().mean()
        print(f"epoch {epoch}: loss batch cuối = {loss.item():.3f}, val accuracy = {acc.item():.2f}")

Một đường thẳng không tách được điểm trong và ngoài vòng tròn, nhưng mạng có lớp ẩn và ReLU thì làm được: accuracy trên 100 điểm giữ riêng tăng nhanh trong vài epoch đầu rồi đứng ở mức cao, còn loss tiếp tục giảm. model.train() và model.eval() bật, tắt các lớp chỉ dùng khi train (Dropout, BatchNorm ở P2.2); tập thói quen gọi chúng ngay từ bây giờ.

Lưu và nạp model

Model đã train chỉ là các tensor tham số. state_dict() là dict tên lớp → tensor:

torch.save(model.state_dict(), "model.pt")             # lưu ra file

model2 = nn.Sequential(nn.Linear(2, 16), nn.ReLU(), nn.Linear(16, 2))   # cùng kiến trúc
model2.load_state_dict(torch.load("model.pt"))

with torch.no_grad():
    w -= 0.1 * w.grad
print(w.item(), ((w * 2 - 5) ** 2).item())

Từ numpy sang PyTorch

code

Viết lại hai hàm softmax(Z) và accuracy(logits, y) bằng PyTorch (không dùng torch.softmax có sẵn), rồi so kết quả với bản numpy và với torch.softmax.

Gợi ý

Thay axis bằng dim, keepdims bằng keepdim, .max(axis=...) của numpy bằng .max(dim=...).values (PyTorch trả về cả giá trị lẫn vị trí).

Code tham khảo 
import numpy as np, torch

def softmax_np(Z):
    E = np.exp(Z - Z.max(axis=1, keepdims=True))
    return E / E.sum(axis=1, keepdims=True)

def softmax_t(Z):
    E = torch.exp(Z - Z.max(dim=1, keepdim=True).values)
    return E / E.sum(dim=1, keepdim=True)

def accuracy_t(logits, y):
    return (logits.argmax(dim=1) == y).float().mean().item()

torch.manual_seed(0)
Z = torch.randn(5, 3) * 10
print(np.allclose(softmax_t(Z).numpy(), softmax_np(Z.numpy()), atol=1e-6))
print(torch.allclose(softmax_t(Z), torch.softmax(Z, dim=1)))
print(accuracy_t(Z, torch.tensor([0, 1, 2, 0, 1])))

Tìm giá bán tối ưu bằng autograd

ứng dụng

Dùng: tensor requires_grad, backward, .grad, torch.no_grad, zero_.

Một sản phẩm có giá vốn 200 nghìn. Khi bán giá p (nghìn đồng), số lượng bán mỗi tháng ước tính là 1000 · exp(−p / 400). Lợi nhuận là (p − 200) · số lượng. Dùng autograd để làm gradient ascent (đi theo chiều gradient để lợi nhuận tăng), bắt đầu từ giá 300, rồi so với đáp án giải tích (đạo hàm bằng 0 tại p = 200 + 400 = 600).

import torch
p = torch.tensor(300.0, requires_grad=True)

def loi_nhuan(p):
    return (p - 200) * 1000 * torch.exp(-p / 400)
# TODO: lặp 2000 bước: tính lợi nhuận, backward, cập nhật p += lr * p.grad, xóa grad
Gợi ý

Gradient ở đây có độ lớn khoảng vài trăm, nên learning rate phải nhỏ (ví dụ lr = 0.5). Cập nhật trong with torch.no_grad(): và nhớ p.grad.zero_() sau mỗi bước.

Code tham khảo 
lr = 0.5
for step in range(2000):
    ln = loi_nhuan(p)
    ln.backward()
    with torch.no_grad():
        p += lr * p.grad           # dấu + : đi lên để TĂNG lợi nhuận
    p.grad.zero_()
    if step % 400 == 0:
        print(f"bước {step}: giá {p.item():.1f}, lợi nhuận {ln.item() / 1000:.1f} triệu")
print(f"giá tối ưu ≈ {p.item():.1f} (giải tích: 600)")

Hồi quy tuyến tính ba cách

Bạn giải cùng một bài toán ba lần, mỗi lần để PyTorch làm hộ nhiều hơn, rồi kiểm tra ba cách cho cùng đáp án. Sau bài này, mọi vòng train ở P2 sẽ chỉ là phiên bản lớn hơn của cách thứ ba.

Dữ liệu: X shape (500, 3), y = X @ [2, -1, 0.5] + 3 + nhiễu.

Các bước

  1. numpy, gradient tự tính: viết công thức gradient của MSE theo w (3 số) và b bằng tay, lặp gradient descent 500 bước.
  2. PyTorch autograd: w, b là tensor requires_grad=True, dùng backward() thay cho công thức, cập nhật trong torch.no_grad().
  3. nn.Module + optimizer: nn.Linear(3, 1), nn.MSELoss(), torch.optim.SGD, vòng train 5 dòng.
  4. In w, b của cả ba cách cạnh nhau và so với đáp án thật.

Xong khi

  • Ba cách cho w, b chênh nhau dưới 1e-4 (cùng learning rate, cùng số bước, cùng giá trị khởi đầu 0).
  • Bạn giải thích được từng dòng của cách 3 tương ứng với dòng nào ở cách 1.
Code tham khảo 
import numpy as np, torch, torch.nn as nn
rng = np.random.default_rng(0)
X = rng.normal(size=(500, 3)).astype(np.float32)
y = (X @ np.array([2, -1, 0.5], dtype=np.float32) + 3 + rng.normal(0, 0.1, 500)).astype(np.float32)
lr, steps = 0.1, 500

# 1. numpy: gradient của MSE = mean((Xw + b - y)²) là 2/n · Xᵀ(err) và 2 · mean(err)
w1, b1 = np.zeros(3, np.float32), np.float32(0)
for _ in range(steps):
    err = X @ w1 + b1 - y
    w1 -= lr * 2 * X.T @ err / len(y)
    b1 -= lr * 2 * err.mean()

# 2. autograd
Xt, yt = torch.from_numpy(X), torch.from_numpy(y)
w2 = torch.zeros(3, requires_grad=True); b2 = torch.zeros((), requires_grad=True)
for _ in range(steps):
    loss = ((Xt @ w2 + b2 - yt) ** 2).mean()
    loss.backward()
    with torch.no_grad():
        w2 -= lr * w2.grad; b2 -= lr * b2.grad
    w2.grad.zero_(); b2.grad.zero_()

# 3. nn.Module + optimizer
model = nn.Linear(3, 1)
nn.init.zeros_(model.weight); nn.init.zeros_(model.bias)
opt = torch.optim.SGD(model.parameters(), lr=lr)
loss_fn = nn.MSELoss()
for _ in range(steps):
    opt.zero_grad()
    loss = loss_fn(model(Xt).squeeze(1), yt)
    loss.backward()
    opt.step()

w3, b3 = model.weight.detach().numpy().ravel(), model.bias.item()
print("numpy   ", w1.round(4), round(float(b1), 4))
print("autograd", w2.detach().numpy().round(4), round(b2.item(), 4))
print("nn      ", w3.round(4), round(b3, 4))
print("chênh lớn nhất:", max(np.abs(w1 - w3).max(), abs(b1 - b3)))
