P10.2

Hồ sơ: CV, GitHub, LinkedIn, Hugging Face

Giai đoạn P10 · Portfolio và đi làmTuần 24–45Có nội dung đầy đủ

Dự án tốt mà không ai thấy thì như không có. Bài này giúp bạn làm CV một trang viết theo kết quả, trang GitHub và Hugging Face gọn gàng, hồ sơ LinkedIn tìm thấy được, và luyện viết kỹ thuật bằng tiếng Anh, vì phần lớn việc remote AI dùng tiếng Anh.

CV một trang theo kết quả

Người lọc CV đọc rất nhanh. Mỗi dòng kinh nghiệm nên theo mẫu:

Động từ + việc đã làm + bằng công cụ gì + kết quả đo được
Yếu Mạnh
"Responsible for building a chatbot" "Built a RAG assistant over 120 pages of academic regulations; hybrid search + reranking raised recall@5 from 0.71 to 0.86"
"Worked with LLMs" "Fine-tuned Qwen2.5-1.5B with LoRA for Vietnamese email extraction, 96% field accuracy vs 84% few-shot"

Thứ tự cho người mới: tên + liên hệ + link GitHub/portfolio, tóm tắt 2 dòng, dự án (3 dự án chủ lực), kinh nghiệm (thực tập, freelance), kỹ năng (nhóm theo mảng, chỉ ghi thứ bạn đã dùng trong dự án), học vấn. Một trang, file PDF, tên file có tên bạn.

GitHub và Hugging Face

  • Profile README: 3–5 dòng giới thiệu, 3 dự án chủ lực kèm một câu và link demo.
  • Ghim 3–6 repo tốt nhất; repo bài tập theo khóa học thì gom vào một repo hoặc để private.
  • Mỗi repo ghim: README tốt, mô tả ngắn, topics, link demo.
  • Hugging Face: model và LoRA có model card, Space demo. Đây là nơi người trong ngành AI hay tìm.

LinkedIn

  • Tiêu đề rõ vai trò mong muốn: "AI Engineer | LLM apps, RAG, diffusion | Python, PyTorch".
  • Mục Featured: 3 dự án, blog.
  • Đăng bài ngắn khi xong mỗi dự án: vấn đề, cách làm, một con số, link. Đều đặn quan trọng hơn hay.

Viết kỹ thuật bằng tiếng Anh

  • Câu ngắn, chủ ngữ rõ, động từ mạnh: "We reduce latency by caching embeddings" thay vì câu bị động dài.
  • Một ý mỗi đoạn, mở đoạn bằng ý chính.
  • Dùng đúng thuật ngữ ngành, không dịch từ tiếng Việt theo từng chữ.
  • Nhờ người hoặc Claude góp ý văn phong, nhưng nội dung và số liệu phải là của bạn.

Ghi nhớ: mọi con số trong CV phải đến từ dự án thật và giải thích được khi bị hỏi sâu. Phỏng vấn viên thường hỏi "con số này đo thế nào?".

Bài 1

Viết lại dòng kinh nghiệm

khái niệm

Viết lại 3 dòng sau theo mẫu "động từ + việc + công cụ + kết quả" (dùng số liệu thật từ lab của bạn):

  1. "Học về deep learning và làm project phân loại ảnh."
  2. "Tham gia dự án làm benchmark video."
  3. "Làm đồ án web tạo ảnh bằng AI."
Lời giải

Ví dụ (thay bằng số của bạn): 1. "Trained a CIFAR-10 CNN from scratch in PyTorch (custom training loop, checkpoint/resume), reaching 78% test accuracy." 2. "Curated and annotated egocentric video clips for a team-built benchmark, defining labeling guidelines and quality checks for N clips." 3. "Rebuilt my text-to-image graduation project from first principles: implemented DDPM, trained a style LoRA on 20 images, and deployed a Gradio app; blind survey preferred LoRA outputs 69% of the time."

Bài 2

Tóm tắt hai dòng

khái niệm

Viết phần tóm tắt 2 dòng đầu CV bằng tiếng Anh: bạn là ai, mạnh ở đâu, đang tìm gì.

Lời giải

Ví dụ: "AI engineer focused on LLM applications and generative vision. Built RAG systems with measured retrieval quality and fine-tuned diffusion and language models; looking for remote AI engineering roles." Tránh tính từ chung chung ("passionate", "hard-working"); dùng việc cụ thể.

Bài 3

Kiểm tra trang GitHub

thiết kế

Lập checklist 10 mục để kiểm tra trang GitHub của bạn trước khi gửi CV, rồi tự chấm.

Lời giải
  1. Ảnh đại diện và tên thật. 2. Profile README có 3 dự án và link demo. 3. Ghim đúng 3–6 repo tốt nhất. 4. Mỗi repo ghim có mô tả và topics. 5. README có ảnh hoặc GIF đầu trang. 6. README có bảng kết quả. 7. README có cách chạy. 8. Không có khóa API hay file .env trong lịch sử commit. 9. Commit message có nghĩa. 10. Repo bài tập lặt vặt đã gom hoặc ẩn.
Bài 4

Đếm chữ cho phần đầu README

tính tay

Người đọc lướt khoảng 250 từ/phút, và bạn muốn phần đầu README đọc xong trong 1,5 phút.

Lời giải

250 × 1,5 = 375 từ. Đặt mọi thông tin quan trọng (một câu, demo, bảng kết quả) trong khoảng này; chi tiết kỹ thuật để phía dưới.

Bộ hồ sơ hoàn chỉnh

Các bước

  1. CV một trang bằng tiếng Anh, 3 dự án chủ lực, mọi dòng có kết quả đo được.
  2. GitHub: profile README, ghim repo, kiểm tra theo checklist ở bài tập 3.
  3. Hugging Face: ít nhất 1 model hoặc LoRA có model card, 1 Space demo.
  4. LinkedIn: tiêu đề, giới thiệu, Featured, kinh nghiệm khớp với CV.
  5. Hai bài blog kỹ thuật tiếng Anh (có thể từ P9.1 và một dự án chủ lực).
  6. Gửi CV cho Claude, nhờ đóng vai nhà tuyển dụng AI Engineer chấm theo thang 1–10 kèm góp ý; sửa và chấm lại.

Xong khi

  • CV qua được bài chấm của Claude đóng vai nhà tuyển dụng (từ 8/10).
  • GitHub, Hugging Face, LinkedIn nhất quán với CV, và mọi link hoạt động.
