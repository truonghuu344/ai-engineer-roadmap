    Xem lời giải

    Dùng khai triển ‖x − y‖² = ‖x‖² + ‖y‖² − 2·x·y. Phần x·y cho mọi cặp điểm chính là phép nhân ma trận X @ Yᵀ, nên không cần vòng for.

    python
    import torchnạp PyTorch
    def pairwise_dist(X, Y):X: (N, D), Y: (M, D) -> ma trận khoảng cách (N, M)

    y2 = (Y ** 2).sum(dim=1).unsqueeze(0)‖y‖² mỗi điểm của Y, shape (1, M)
    d2 = x2 + y2 - 2 * X @ Y.Tbroadcasting thành (N, M): bình phương khoảng cách
    return d2.clamp(min=0).sqrt()clamp tránh số âm rất nhỏ do sai số, rồi lấy căn
    X, Y = torch.randn(5, 3), torch.randn(4, 3)5 điểm và 4 điểm trong không gian 3 chiều
    print(pairwise_dist(X, Y).shape)(5, 4)
    print(torch.allclose(pairwise_dist(X, Y), torch.cdist(X, Y), atol=1e-5))so với hàm có sẵn torch.cdist: True

Module 2: Autograd

Autograd tự động tính đạo hàm: PyTorch ghi lại mọi phép toán thành một đồ thị tính toán, rồi backward() đi ngược đồ thị theo quy tắc chain rule. Đây là cơ chế giúp train mọi neural network.

2.1 Ví dụ đầu tiên

Với y = x² + 3x, đạo hàm dy/dx = 2x + 3. Tại x = 2 thì dy/dx = 7.

python
import torchnạp PyTorch
x = torch.tensor(2.0, requires_grad=True)biến x = 2, yêu cầu PyTorch theo dõi để tính đạo hàm
y = x ** 2 + 3 * xy = x² + 3x, PyTorch ghi lại các phép tính
y.backward()tính đạo hàm dy/dx bằng lan truyền ngược
print(x.grad)tensor(7.) vì dy/dx = 2x + 3 = 7 tại x = 2

2.2 Đồ thị tính toán

python
w = torch.randn(3, requires_grad=True)trọng số w (3 phần tử), cần tính gradient
b = torch.randn(1, requires_grad=True)bias b, cần tính gradient
x = torch.tensor([1.0, 2.0, 3.0])dữ liệu đầu vào, không cần gradient
y = (w * x).sum() + bforward: tính y và xây đồ thị tính toán
print(y.grad_fn)<AddBackward0>: phép tính cuối cùng tạo ra y
y.backward()backward: tính dy/dw và dy/db
print(w.grad)dy/dw = x = [1, 2, 3]
print(b.grad)dy/db = 1

Chỉ tensor lá (do bạn tạo với requires_grad=True) mới lưu .grad. backward() chỉ gọi trực tiếp trên scalar; với tensor nhiều phần tử cần truyền gradient=.

Vì vậy trong training luôn gọi optimizer.zero_grad() trước loss.backward().

2.5 Gradient descent thủ công

Tìm x nhỏ nhất cho f(x) = (x − 5)², đáp án x = 5:

python
x = torch.tensor(0.0, requires_grad=True)điểm xuất phát x = 0
lr = 0.1learning rate: bước nhảy mỗi lần cập nhật
for step in range(50):50 bước gradient descent
loss = (x - 5) ** 2hàm cần nhỏ nhất, đáp án đúng là x = 5
loss.backward()tính d(loss)/dx
with torch.no_grad():cập nhật không được ghi vào đồ thị
x -= lr * x.gradđi ngược hướng gradient một bước
x.grad.zero_()xóa gradient cho bước sau
print(x.item())~5.0; .item() lấy số Python từ tensor 1 phần tử

9.1 Scaled dot-product attention

Attention(Q, K, V) = softmax(QK⊤√dk) V
python
import math, torch, torch.nn as nn, torch.nn.functional as Fnạp math (căn bậc hai) và PyTorch
def attention(q, k, v, mask=None):attention viết tay để hiểu công thức
q, k, v: (B, heads, T, d_k)
scores = q @ k.transpose(-2, -1) / math.sqrt(q.size(-1))độ liên quan giữa mọi cặp token, chia √d_k: (B, h, T, T)
if mask is not None:nếu có mask (ví dụ không cho nhìn tương lai)
scores = scores.masked_fill(mask == 0, float("-inf"))chỗ bị che gán -vô cùng để softmax ra 0
return F.softmax(scores, dim=-1) @ vchuẩn hóa thành trọng số rồi lấy trung bình có trọng số của v
PyTorch có sẵn bản tối ưu (FlashAttention khi có thể):

    class Attention(nn.Module):self-attention hai chiều (không causal)
    def __init__(self, d, heads):d: kích thước vector, heads: số head

    def __init__(self, d, heads):cấu hình

    self.norm, self.head = nn.LayerNorm(d), nn.Linear(d, n_cls)chuẩn hóa cuối và head phân loại

self.drop = nn.Dropout(0.1)dropout chống overfit
self.sentiment_head = nn.Linear(h, 3)đầu ra 1: 3 lớp cảm xúc

return self.sentiment_head(cls), self.topic_head(cls)trả về điểm cảm xúc và điểm chủ đề

Dự án 3: Phân đoạn hành động trong video egocentric (hướng nghiên cứu)

Gán nhãn hành động cho từng frame của video quay từ camera đội đầu, ví dụ lấy → mở → đổ → khuấy. Bạn viết lại từ đầu model MS-TCN (CVPR 2019) rồi so kết quả với bài báo. Tái hiện được một bài báo là bằng chứng mạnh nhất cho nhà tuyển dụng nghiên cứu, và đề tài này gần trực tiếp với công việc cắt và gán nhãn video egocentric cho robot.

Dữ liệu là GTEA: 28 video nấu ăn quay từ camera trên đầu, 11 lớp hành động (kể cả nền). Đặc trưng I3D 2048 chiều đã trích sẵn cho từng frame, nên Colab không phải xử lý video thô. Bản trên Hugging Face chỉ nặng 357 MB, trong khi bản gốc gộp ba bộ dữ liệu nặng 30 GB.

Kiến thức dùng: Module 5 (Dataset cho chuỗi), 6 (Conv, residual), 8 (dữ liệu chuỗi), 9 (Transformer, cho phần mở rộng), 10 (training, checkpoint).

Model MS-TCN và hàm loss:

python
import torch.nn as nn, torch.nn.functional as Flayer và hàm của PyTorch
class DilatedResidual(nn.Module):một lớp conv giãn có kết nối tắt
def __init__(self, dilation, ch):dilation: khoảng cách giữa các điểm conv nhìn vào
super().__init__()khởi tạo nn.Module
self.conv = nn.Conv1d(ch, ch, 3, padding=dilation, dilation=dilation)conv 1D theo thời gian, nhìn xa dần nhờ dilation
self.proj = nn.Conv1d(ch, ch, 1)conv 1x1 trộn các kênh
self.drop = nn.Dropout(0.5)dropout mạnh như bài báo
def forward(self, x):x: (B, ch, T)
return x + self.drop(self.proj(F.relu(self.conv(x))))conv -> ReLU -> 1x1 -> dropout, cộng lại đầu vào
class Stage(nn.Module):một stage gồm 10 lớp giãn
def __init__(self, in_dim, ch, n_cls, layers=10):in_dim: số kênh vào; n_cls: số lớp hành động
super().__init__()khởi tạo nn.Module
self.inp = nn.Conv1d(in_dim, ch, 1)thu kênh vào về 64
self.layers = nn.Sequential(*[DilatedResidual(2 ** i, ch) for i in range(layers)])dilation 1, 2, 4, ..., 512: nhìn được rất xa
self.out = nn.Conv1d(ch, n_cls, 1)ra điểm cho từng lớp tại mỗi frame
def forward(self, x):luồng tính
return self.out(self.layers(self.inp(x)))(B, n_cls, T)
class MSTCN(nn.Module):nhiều stage nối tiếp
def __init__(self, n_cls, in_dim=2048, ch=64, stages=4):4 stage như bài báo
super().__init__()khởi tạo nn.Module
self.first = Stage(in_dim, ch, n_cls)stage đầu đọc đặc trưng I3D 2048 chiều
self.refine = nn.ModuleList([Stage(n_cls, ch, n_cls) for _ in range(stages - 1)])3 stage sau đọc dự đoán của stage trước
def forward(self, x):x: (B, 2048, T)
outs = [self.first(x)]dự đoán của stage đầu
for stage in self.refine:mỗi stage tinh chỉnh dự đoán của stage trước
outs.append(stage(F.softmax(outs[-1], dim=1)))đưa xác suất của stage trước vào stage sau
return outslist (B, n_cls, T), dùng để tính loss cho mọi stage
def mstcn_loss(outs, y, lam=0.15):loss của MS-TCN
loss = 0cộng dồn loss
for o in outs:tính cho từng stage
loss = loss + F.cross_entropy(o, y)loss phân loại từng frame
logp = F.log_softmax(o, dim=1)log xác suất
diff = (logp[:, :, 1:] - logp[:, :, :-1].detach()) ** 2chênh lệch giữa hai frame liền kề
loss = loss + lam * torch.clamp(diff, max=16).mean()phạt dự đoán nhảy loạn giữa các frame (smoothing loss)
return losstổng loss
Train: batch 1 video, Adam lr 5e-4, 50 epoch; dự đoán cuối = outs[-1].argmax(1)
